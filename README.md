# FusionXplorer

A modern, Material Design 3 file explorer for Android with a clean, intuitive interface.

> **Note**: This is the source code repository. For pre-built APKs, check the [Releases](https://github.com/Blink-Chase/FusionXplorer/releases) section.

## 📱 Features

### v1.1.0 (Current)
- **File Management**
    - Browse and manage files with ease
    - Copy, move, rename, and delete files
    - Search functionality
    - Sort and view options

- **Modern UI**
    - Material Design 3 theming
    - Dark/Light theme support
    - Smooth animations
    - Intuitive navigation

- **Storage Tools**
    - Storage usage visualization
    - Quick access to storage information
    - Clean and organized interface

### v1.0.0
- Basic file operations (browse, open, delete)
- Material Design 3 implementation
- Initial release

## 📥 Download

Get the latest APK from the [Releases](https://github.com/Blink-Chase/FusionXplorer/releases) page.

## ℹ️ About

FusionXplorer is designed to be a simple yet powerful file manager for Android, focusing on a clean user experience and essential functionality.

This project is currently in active development. The source code is available for reference and educational purposes.
